The feed stops spotting callers as if they were calling CQ. The web page is easier to use: settings show which field is wrong, the map labels no longer cross, and the README shows the signal's way through the code.

## Feed: a caller is not calling

What the station hold of v0.8.2 left in a CWT evening was a caller read as calling CQ on the runner's frequency. In "CQ CWT SP3FSM PA3AAV", PA3AAV answers right after the runner's CQ in the same channel and fell inside the CQ window. A name-and-number exchange ("PA3AAV GE GERT 2624") has no RST, so the rule that takes such a call back never fired. Two extractor rules, both on by default (details and numbers: [`docs/LIVE-AIR.md`](https://github.com/ok1hra/skimmer-for-linux/blob/v0.8.4/docs/LIVE-AIR.md#a-caller-is-not-calling-2026-11-19)):

- **A CQ window belongs to the call it names first.** A different call later in the same window does not inherit it. `SKIM_CALL_CQNAMED=0` turns it off.
- **A name and a number mark a call worked.** A call followed by a name and then a number, or a short state, is being worked. A CQ window that reached it across an over break is withdrawn. `SKIM_CALL_NAMEEXCH=0` turns it off.

Live taps replayed against the feed of v0.8.3:

| window | spots | calls | over 150 Hz off RBN's frequency |
|---|---|---|---|
| weekday afternoon, 3 h | 605 → 597 | 318 → 311 | 14 → 14 |
| 17.5 h, 7 bands | 2478 → 2356 | 907 → 876 | 92 → 86 |
| CWT evening, 3.3 h | 1011 → 923 | 431 → 399 | 68 → 56 |

Most of the calls the rules drop were heard by RBN only elsewhere, or never. Of the stations CW Skimmer Server finds in the CWT evening, this skimmer finds 263 → 260.

## Web page

- **Settings.** A wrong field turns red, with what is wrong under it. A refusal from the skimmer marks the field it names. An empty field whose hint is the default (ports, delay, ppm, minutes) takes the hint. An empty Hub port no longer stops a save when no hub is used. A blank port in the config file now means the default: before, an empty feed or web port turned that port off (0).
- **Map.** The centre field is gone. The centre is the locator from Settings, else your call's DXCC, else Paris. The locator leaves the skimmer as its square only (JN18), for everyone. The dB button is now **SNR** and shows the number also with the calls off. Labels move out along the line from the centre on straight leaders that never cross.
- **Statistics.** Spots per hour on a **linear or logarithmic** axis. The CPU temperature line is coloured by its value: green, amber from 70 °C, red from 85 °C. The totals table has a bar beside every value. Active decoders use one calm ramp for CW and RTTY.
- **Waterfall.** One speaker icon: grey and crossed out while muted, green while listening.
- **README.** A diagram of the signal's way from the Red Pitaya to the telnet feed, each step linked to its code.

## Before you upgrade

Nothing to do. The config and the statistics file are as in v0.8.3, and going back to v0.8.3 needs nothing either. The feed sends a few percent fewer spots (up to 9 % in a CWT evening), the same stations on their own frequency.
