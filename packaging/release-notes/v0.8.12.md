Web page fixes on top of v0.8.11:
- choosing a new default CW engine in Settings now reaches every band that follows the default;
- a station you listen to on the waterfall stays on when you switch tabs;
- the bands table and the DX cluster on the status page are easier to read.

The decoders and the feed are as in v0.8.11.

## Settings: a band's CW engine can follow the default

- **The bug:** Settings → Bands kept a fixed engine for every band. Switching *CW engine* (Decoding) from v3.1 to v4.0 DeepCW in one save left every band on v3.1 (`cw:v3`), and turned the bands that had been set to v4 into plain `cw`. Only the bands set to v4 beforehand ran v4.
- **Now:** each band's engine list starts with **default (…)**, written as `cw` in `[bands]`, which follows *CW engine*. A band set to a named engine keeps it whatever the default becomes.
- A band that runs the default's engine reads back as *default*, because the config file cannot tell the two apart.
- **If you switched the default in v0.8.11**, check Settings → Bands: set the bands you want on the new default back to *default (…)* and save.

## The bands table on the status page

- **The continents' heat map fades out at its edges.** It used to stop sharply at the EU and OC columns.
- **Five colours far apart in the bars:** CW blue, RTTY orange, FT8 violet, FT4 green, WSPR red, with a thin gap between two parts. The pastel blue, violet and pink of v0.8.11 ran together. Statistics keeps its colours.
- **With a mode left out, the total follows the count:** `61 (188)` means 61 spots of the modes counted, 188 of all modes.

## Listening from another tab

- **Before:** leaving the waterfall closed its stream after 30 s, so a station you were listening to went quiet a while after you switched to Status.
- **Now:** while the audio is on, the stream stays. A pill in the corner shows the band and frequency heard, *mute* stops it, and a click on it leads back to the waterfall.
- Muted, or not listening, the stream still stops 30 s after you leave, so the skimmer computes nothing for a page nobody watches.

## The DX cluster in wifilt's colours

- **Text:** one light green for every cell, striped rows, as in the DX cluster of [WIFILT](https://github.com/ok1hra/wifilt).
- **Distance and dB** run from dark to bright green over the rows shown, so the farthest and the loudest station on screen are the brightest.
- dB's meter has 6 bars on the same scale.

## Install

A skimmer on v0.8.8 or later with `[update] mode=auto` (the default) installs this release by itself at its update hour; Settings → Updates → *Install now* does it at once. By hand:

```sh
mv skimmer-headless-0.8.12-x86_64.AppImage skimmer-headless-x86_64.AppImage
chmod +x skimmer-headless-x86_64.AppImage
./skimmer-headless-x86_64.AppImage
```

Coming from v0.8.10 or older and running as a systemd service: run `--install-service` once more (see v0.8.11).
